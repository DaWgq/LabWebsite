# Qoder Project

This repository contains the Qoder project with the following structure:

- `index.html` - Main HTML file
- `Requirement.md` - Requirements document
- `assets/` - Contains CSS, images, and JavaScript files
  - `css/styles.css` - Stylesheet
  - `img/` - Image assets
  - `js/app.js` - JavaScript application file
- `content/` - JSON data files
  - `news.json` - News content
  - `people.json` - People information
  - `publications.json` - Publications data
  - `research.json` - Research data

## Setup

To run this project locally, simply open `index.html` in a web browser.

This appears to be a static website or web application with content stored in JSON files, likely for dynamic content loading.
